# وب‌سایت مجموعهٔ مهندسی

وب‌سایت معرفی فارسی با React و Vite، بدون حساب کاربری، بک‌اند یا ذخیره‌سازی اطلاعات بازدیدکننده.

## اجرای توسعه

نیازمند Node.js 22.12 یا جدیدتر؛ این پروژه با Node.js 22.23 تست شده است.

```sh
npm ci
npm run dev
```

سایت در http://127.0.0.1:5173 باز می‌شود. تغییر فایل‌های `src` در مرورگر به‌روز می‌شود.

## ساخت و پیش‌نمایش خروجی

```sh
npm run build
npm run preview
```

پیش‌نمایش خروجی در http://127.0.0.1:4173 است. پوشهٔ `dist` خروجی خودکار Vite است؛ فایل‌هایش را مستقیم ویرایش نکنید. برای مشاهده، از سرور Vite استفاده کنید، نه بازکردن `dist/index.html` با `file://`.

برای انتشار روی هاست استاتیک، محتوای `dist` را بارگذاری کنید. ناوبری با hash انجام می‌شود و به تنظیم بازنویسی مسیرهای سرور احتیاج ندارد.

## ساختار پروژه

- `index.html`: ورودی HTML و متادیتای سایت.
- `src/main.jsx`: کامپوننت‌های React، صفحات، منوی موبایل، فیلترها و پنجرهٔ مشخصات قطعات.
- `src/Artwork.jsx`: آیکن‌ها و مدل‌های مفهومی SVG.
- `src/styles.css`: کانتینر مرکزی ۱۱۸۰ پیکسل، چیدمان واکنش‌گرا و تم تیرهٔ سرمه‌ای، سطوح آبی تیره و متن‌های روشن.
- `src/data.js`: برندها، مدل‌های PLC/HMI، قطعات و فهرست مستندات.
- `public/files/`: محل PDFهای قابل انتشار.

فونت فارسی **استعداد (Estedad)** با پکیج `@fontsource-variable/estedad` همراه سایت بسته‌بندی می‌شود و برای بارگذاری فونت به Google Fonts وصل نمی‌شود. فونت جایگزین Tahoma است.

## تکمیل محتوای شرکت

نام و نشان فعلی موقت است. برندها و پروژه‌ها نمونهٔ نمایشی هستند و باید قبل از انتشار رسمی تأیید یا جایگزین شوند. اطلاعات تماس، سابقهٔ همکاری و نام مشتری واقعی ساخته نشده است.

برای افزودن PDF، فایل را در `public/files` قرار دهید و در آرایهٔ `documents` در `src/data.js` اضافه کنید:

```js
{ title: 'کاتالوگ مجموعه', file: 'files/catalog.pdf' }
```

فایل‌های داخل `public` هنگام build به `dist` کپی می‌شوند.

## اعتبارسنجی

خروجی production در Chromium با عرض‌های ۳۷۵، ۶۴۰، ۷۶۸، ۱۰۲۴، ۱۴۴۰ و ۱۹۲۰ پیکسل بررسی شده است. پنج صفحه، تراز کانتینر و نبود اسکرول افقی، بارگذاری فونت محلی، منوی موبایل، فیلترهای PLC/HMI و قطعات، پنجرهٔ مشخصات، کلید Escape و بازگشت فوکوس به دکمهٔ قطعه تست شدند.

## ورودی و جداسازی بخش‌ها

در آدرس اصلی یا `#home` فقط صفحهٔ انتخاب «PLC و HMI» یا «طراحی و ساخت قطعات» نمایش داده می‌شود. هر انتخاب به فضای مستقل خودش می‌رود:

- اتوماسیون: `#automation`، `#automation/about`، `#automation/partners`
- قطعات: `#manufacturing`، `#manufacturing/about`، `#manufacturing/partners`

هدر، فوتر و محتوای هر فضا فقط متعلق به همان بخش است. گزینهٔ «تغییر بخش» کاربر را به صفحهٔ انتخاب برمی‌گرداند. لینک مستقیم و رفرش در بخش انتخاب‌شده پشتیبانی می‌شود؛ انتخاب در کوکی یا حافظهٔ مرورگر ذخیره نمی‌شود. مسیرهای ناشناخته به صفحهٔ انتخاب هدایت می‌شوند.
